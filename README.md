# Female AI Assistant APK Project

This is a simple Android AI assistant app with:

- Female face/avatar on screen
- Voice listening button
- Text chat
- Text-to-speech female-style voice output
- OpenAI-compatible API connection
- GitHub Actions APK builder, so you can build without Android Studio

## How to build APK without Android Studio

1. Create a new GitHub repository.
2. Upload all files from this project.
3. Go to **Actions** tab.
4. Run **Build Android APK** workflow.
5. Download the artifact named **Female-AI-Assistant-APK**.
6. Install `app-debug.apk` on your Android phone.

## How to use

1. Install the APK.
2. Open the app.
3. Paste your API key in the API Key box.
4. Tap **Save Key**.
5. Tap **Talk to Her** and speak.

## Important

Do not share your API key with anyone.
This app needs internet and microphone permission.
